# PanalSuiteApp

## Descripción

PanalSuite es una aplicación móvil orientada a la gestión
de solicitudes y tickets, permitiendo administrar usuarios,
roles y estados de las solicitudes.

## Tecnologías utilizadas

- Kotlin
- Jetpack Compose
- Material 3
- MVVM
- Room
- Retrofit
- JUnit
- Gradle
- GitHub

## Funcionalidades actuales

- Inicio de sesión.
- Gestión de tickets.
- Creación de solicitudes.
- Filtrado de solicitudes por estado.
- Gestión de usuarios y permisos.
- Almacenamiento local.

## Ejecución

Abrir el proyecto en Android Studio, sincronizar Gradle
y ejecutar la aplicación en un emulador o dispositivo físico.

## Pruebas unitarias

Ejecutar desde la terminal:

    .\gradlew.bat testDebugUnitTest
